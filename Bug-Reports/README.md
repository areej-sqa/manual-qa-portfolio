# Bug Reports

This folder contains sample bug reports demonstrating my approach to identifying, documenting, and communicating software defects.

The reports include functional, UI, validation, data integrity, authorization, integration, mobile, and edge-case defects.

Each bug report is structured to provide developers and product teams with clear reproduction steps, expected and actual behavior, severity, priority, environment details, and supporting evidence where applicable.

## Bug Report Structure

- Bug ID
- Title
- Environment
- Severity
- Priority
- Preconditions
- Steps to Reproduce
- Expected Result
- Actual Result
- Reproducibility
- Evidence
- Additional Notes
